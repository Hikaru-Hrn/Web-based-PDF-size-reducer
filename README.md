# Проект: Web-сервис компрессии PDF-документов
[English version](README.en.md) | **Русская версия**

### Общее описание

Целью проекта является разработка легковесного и производительного веб-сервиса для оптимизации размера PDF-файлов. Сервис решает проблему передачи объемных документов через различные сервисы с лимитами на размер вложений (например gmail).
### Архитектура решения
* **Backend**: FastAPI (Python) 

* **Обработка данных**: Ghostscript — утилита, используемая в качестве основного движка сжатия за счет прямой манипуляции объектами PDF.

* **Frontend**: Адаптивный веб-интерфейс с использованием чистых HTML, CSS и JavaScript. А так же используется Jinja2, чтобы сделать HTML динамическим

* **Infrastructure**: Контейнеризация приложения с помощью Docker для обеспечения идентичности сред разработки и эксплуатации.  

* Технологический стек (Проектируемый)
  * **Язык**: Python 3.11+  
  * **Фреймворк**: FastAPI  
  * **Системные зависимости**: Ghostscript  
  * **Сборка**: Docker  
  * **Среда исполнения**: Fedora Linux (разработка), Linux-based Docker Image (продакшн)

### Планируемые возможности
  * Загрузка файлов методом Drag-and-Drop.  
  * Автоматическая очистка временных файлов с сервера для обеспечения приватности и экономии места.
